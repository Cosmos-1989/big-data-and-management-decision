# 综合项目：SiFactory-like 企业制造决策系统原型

## 最低要求

1. 一个规范化数据库或湖仓一体（lakehouse）分层数据集
2. 一个 KPI 运营看板
3. 一个预测模型
4. 一个因果评估或策略评估模块
5. 一个优化或行动推荐模块
6. 一个业务本体、行动与情景（ontology/action/scenario）原型
7. 一份面向管理者的决策备忘录（decision memo）
8. 一份技术说明文档
9. 可复现实验环境
10. 一份 AI 使用记录，说明 AI 生成内容、人工校验和采纳范围

## 建议题目

- 半导体制造 KPI 诊断与改善建议：围绕 Yield、OEE、Cycle Time、WIP、OTD 建立运营看板和管理备忘录。
- SiFactory-like 制造决策系统原型：模拟“发现问题 -> 查数据 -> 分析诊断 -> 提决策建议”的闭环。
- AI 问数与 SQL 审计助手：自然语言问题生成候选 SQL，并经过指标字典、权限、行数和分母检查。
- AI 辅助生产排程：结合需求、WIP、设备能力、交期和约束，生成可解释排程建议。
- 制造流程瓶颈与返工诊断：基于批次流转（lot flow）或订单到收款事件日志（order-to-cash event log）开展流程挖掘。
- 客户流失与干预策略：围绕客户运营开展预测与策略设计，并说明因果评估依据或行动收益的适用边界。

## 推荐主线

优先推荐围绕半导体制造模拟场景开展：

```text
发现问题 -> 查询 KPI -> 下钻 M13 要素 -> 预测风险 -> 评估干预
-> 生成优化/行动建议 -> 形成 decision memo -> 展示可复现原型
```

## AI 使用要求

允许使用 AI 工具辅助生成 SQL、Python 代码、图表说明和管理备忘录初稿，但必须满足：

1. 保留关键提示词或交互摘要；
2. 标注哪些内容由 AI 生成，哪些经过人工修改；
3. 对 AI 生成 SQL 进行指标口径、权限、行数和分母检查；
4. 对 AI 生成的管理建议说明证据来源和不能支持的结论；
5. 不得把 AI 输出直接作为最终决策结论。

## 企业智能体扩展任务

将智能体作为上述制造决策原型的受控执行层，或选择制度问答、办公协作、客户咨询分流作为同等规模的企业场景。先明确业务对象、责任人、允许行动和基准流程，再选择 Chatflow、Workflow 或二者的组合。选型须说明知识检索、工具、Skills、运行控制和多角色协作分别承担何种职责；不要求为展示技术而引入无必要的 GraphRAG 或多智能体。

阅读[第14章企业AI Agent专题](../docs/lecture_notes/14_ai_agent.md)，复现四个教学实验，再选择一个场景形成可汇报、可验证、可分阶段试点的方案。使用固定规则的教学结果不能作为真实模型效果或真实企业经营改善的证据。

### 项目交付与验收

| 交付物 | 必须能够核验的内容 |
|---|---|
| 场景与基准说明 | 目标对象、当前流程、业务问题、成本、权限、可观察的完成条件 |
| 知识库设计 | 文件解析、切分、元数据、权限与有效期、检索和重排、冲突与引用核查；说明是否需要关系图 |
| 技术架构与契约 | Chatflow/Workflow分工，输入输出模式，Skill适用范围，工具前后置条件与失败分支 |
| 多角色与运行控制 | 管理、执行、评审、工具角色的依赖与交接；预算、终止、检查点、幂等、审批与人工接管 |
| 部署与治理方案 | 数据与模型所在位置、网络边界、身份权限、日志保护、版本登记、更新、备份与回滚 |
| 评测与可复现证据 | 固定问题集、基准与对照、引用准确性、任务完成率、违规率、人工复核时间、端到端延迟和总成本 |
| 试点与规模化计划 | 只读或建议模式、有限授权范围、责任人、准入和停用条件、阶段验收、新范围复测 |
| 管理汇报与技术附件 | 方案选择理由、未解决问题、责任分配、证据限制，以及可运行代码和完整AI使用记录 |

生产线案例必须记录事件、设备、批次、SOP版本、维修与质检事实及责任人。模型不直接执行设备停启；安全联锁与授权操作保持在既有设备控制和作业制度中。即使维修已完成，缺少质检或有效批准时也不得声称“可以恢复生产”。审批绑定对象与版本，重复事件或响应丢失不得产生重复维护工单。

### 评价量规

场景与基准10分，证据与知识库15分，任务契约及流程15分，运行控制与权限15分，协作设计10分，部署运维10分，评测与复现15分，试点与管理汇报10分，共100分。合理解释为何采用单智能体、词法检索或人工审核，也可以获得相应设计分。越权泄露、未经批准的外部操作、把模拟结果写成真实企业结果，均须修正并重新验收。
