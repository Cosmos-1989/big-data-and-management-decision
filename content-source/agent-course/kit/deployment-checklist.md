# 部署与试点检查表

| 检查对象 | 需保留的证据 | 未满足时的处理 |
|---|---|---|
| 任务与身份 | 业务对象、责任人、角色、允许读写及停止条件 | 保持只读或草稿 |
| 数据流 | 文档、索引、模型请求、工具参数、日志与备份位置 | 不接入受限资料 |
| 模型与组件 | 来源、许可、固定版本、上下文及结构化输出测试 | 保留既有基准 |
| 网络与密钥 | 出站范围、服务身份、凭据存储和轮换 | 不授予外部工具调用 |
| 知识库 | 原文、解析校验、页码、版本、有效期、ACL继承 | 返回缺失或冲突 |
| 运行控制 | 调用预算、超时、允许工具、审批绑定、检查点与幂等 | 停止并转人工 |
| 独立评测 | 固定任务集、故障与越权样本、引用、完成状态、人工时间和成本 | 不扩大范围 |
| 容量与恢复 | 端到端延迟、峰值负载、排队、备份恢复和版本回退 | 限流并保留人工流程 |
| 灰度与责任 | 有限范围、基准对照、准入与停用阈值、责任人 | 影子运行 |
| 扩展 | 新业务范围重新核对权限、数据、工具和测试集 | 逐范围重新审批 |

这是一份验收模板，不证明任何平台已完成私有化部署。代码实验只处理课堂数据。云平台、内网模型及工业设备的部署需根据各自官方文档和企业批准的运行约束实施。
