# 作业 03： SQL、KPI 与经营分析

## 任务背景

本作业对应第 3 周课程。学生需要基于 `data/sample/` 中的订单、客户、产品和库存样例数据，或半导体制造样例数据 `semiconductor_kpi_daily.csv`，使用 SQL 构造可解释、可复核的经营 KPI，并用 Python 或手工计算复核关键结果。可选的 AI 问数任务要求审计自然语言转 SQL（NL2SQL）的生成结果。

## 提交内容

1. 一份 SQL 脚本，至少包含以下查询：
   - 按区域计算销售额、毛利、毛利率、准时交付率和平均延期天数；
   - 按产品类别计算同样指标；
   - 使用窗口函数计算每个客户最近三笔订单的累计收入；
   - 检查订单表与客户表、产品表连接前后的行数是否一致。
2. 一份不超过 2 页的经营分析说明：
   - 哪些区域或产品类别表现较好；
   - 哪些 KPI 需要优先关注；
   - 哪些指标不能直接平均，原因是什么。
3. 一条指标字典记录，任选 `gross_margin` 或 `on_time_delivery_rate`，说明对象范围、时间窗口、分子、分母、单位、维度和责任部门。
4. 可选 AI 问数记录：
   - 提出一个自然语言经营问题；
   - 给出 AI 生成或人工生成的候选 SQL；
   - 说明你如何检查指标口径、连接行数、时间窗口和分母；
   - 给出审计后的最终 SQL 和经营解释。

若选择半导体制造数据，SQL 至少包含：

- 按 `area` 和 `work_center` 计算 Yield、OEE、Cycle Time、WIP 和 OTD；
- 用窗口函数计算 3 日滚动 Yield 或 OTD；
- 找出 OEE 低且 WIP 高的工作中心；
- 输出 Yield 或 OEE 的指标字典记录。

## 评分标准

| 项目 | 权重 | 说明 |
|---|---:|---|
| SQL 正确性 | 40% | 查询能运行，连接、分组、条件聚合和窗口函数使用正确。 |
| 指标口径 | 30% | 分子分母、粒度、时间窗口和空值处理说明清楚。 |
| 业务解释 | 20% | 能从 KPI 结果提出有管理含义的观察。 |
| 可复核性 | 10% | SQL 命名清楚，有行数检查或 Python 复核。 |
| AI 问数审计 | 加分 10% | 能清楚说明候选 SQL 的错误、修正和证据边界。 |

## 注意事项

- 毛利率、准时交付率等比率型指标必须保留分子和分母。
- 不要直接平均不同分组的百分比来得到总体百分比。
- 若连接后事实行数变化，需要解释原因并修正查询。
- AI 生成 SQL 只能作为候选草稿，最终结果必须由学生审计和解释。
