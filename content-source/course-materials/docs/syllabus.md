# 《大数据与管理决策基础》课程大纲

## 课程定位

本课程属于“数智化企业运营与优化”微专业，内容包括企业数据建模、统计分析、方案优化与受控执行。

## 学时学分

- 学时：32 学时理论课
- 学分：2 学分
- 适用对象：具有数学、统计、计算机基础的本科生

## 核心能力目标

1. 理解企业运营数据的基本形态。
2. 使用 SQL 和 Python 完成数据抽取、清洗、统计分析和特征构造。
3. 从管理问题出发建立 KPI、统计模型、预测模型和简单优化模型。
4. 区分描述分析、诊断分析、预测分析、因果分析和处方分析。
5. 理解企业级数据平台、语义层、模型部署、数据治理和 AI 决策系统的基本架构。
6. 完成一个小型企业运营决策系统原型。

## 案例与实验

1. 引入半导体制造运营案例，将 Yield、OEE、Cycle Time、WIP、OTD 等 KPI 贯穿企业数据建模、SQL 查询和运营看板分析。
2. 引入教学抽象版 M13 模型，训练学生结合多个运营要素解释 KPI 变化。
3. 在 SQL 章节加入 AI 问数与 NL2SQL 演示，强调候选 SQL 生成、指标口径校验、权限边界和审计日志。
4. 在课程项目中建设制造决策系统原型（SiFactory-like），覆盖“发现问题、查数据、分析诊断、提出决策建议”的完整流程。
5. 将 AI 工具作为受控辅助能力贯穿课程，用于运营方案草拟、SQL 编写、Python 调试、知识库检索和决策备忘录 初稿，但所有输出必须经过人工校验。

## 32 学时教学安排

| 次数 | 主题 | 理论重点 | 企业案例与 AI 融入 |
|:--:|---|---|---|
| 1 | 大数据与管理决策导论 | 数据驱动决策、BI、DSS、决策智能 | AI 辅助生成运营问题拆解草案 |
| 2 | 企业数据模型与业务对象 | 实体、事件、状态、事实表、维度表、KPI 粒度 | 半导体批次、设备、工站、WIP 与 M13 映射 |
| 3 | SQL、KPI 与 AI 问数 | 连接、聚合、窗口函数、指标口径 | 自然语言问数原型（QueryMind-style）与 SQL 审计 |
| 4 | 数据质量与指标治理 | 完整性、一致性、及时性、指标字典 | 良率、OEE 与交付指标的数据质量风险 |
| 5 | 描述统计与运营看板 | 分布、趋势、异常、管理沟通 | 半导体 Yield/OEE/Cycle Time/WIP/OTD 看板 |
| 6 | 统计推断与 A/B 测试 | 抽样、置信区间、p 值、功效、护栏指标 | 工艺或界面改动效果评估 |
| 7 | 预测模型基础 | 监督学习、损失函数、测试集、校准和阈值 | 良率风险、延期风险或流失风险预测 |
| 8 | 因果推断与管理干预 | 潜在结果、混杂、倾向得分、DID | 维护、排程或优惠策略是否改变结果 |
| 9 | 优化与处方分析 | 目标函数、约束、整数规划、敏感性 | AI 辅助生产排程与库存补货 |
| 10 | 流程数据与过程挖掘 | 事件日志、变体、瓶颈、合规异常 | 批次流转与订单到收款流程诊断 |
| 11 | 现代数据平台与语义层 | lakehouse、语义层、数据血缘、指标治理 | SiFactory-like 数据模型和指标层 |
| 12 | MLOps 与分析工程 | 模型部署、监控、漂移、反馈 | AI 辅助 Python 调试和模型日志摘要 |
| 13 | Ontology、Action 与 Scenario | 业务对象、关系、行动、情景推演 | M13 要素映射到对象、行动和场景 |
| 14 | AI Agent、NL2SQL 与 RAG 治理 | 工具调用、知识库、权限、审计 | QueryMind/DataBot-style 教学原型 |
| 15 | 综合项目工作坊 | 端到端系统设计与项目复盘 | SiFactory-like 制造决策系统原型 |
| 16 | 项目答辩与企业点评 | 决策备忘录、技术说明、风险边界 | 企业导师专题分享或项目点评 |

## 考核结构

| 考核项目 | 权重 | 说明 |
|---|---:|---|
| 平时作业 | 20% | SQL、统计推断、建模、优化的小作业 |
| 实验报告 | 25% | 6 次实验，每次提交代码、结果和业务解释 |
| 期中测验 | 15% | 概念、公式、SQL、统计与优化基础 |
| 综合项目 | 30% | 小组完成企业运营决策系统原型 |

## 企业 Agent 专题培训

讲义与实验见[第14讲](#/chapter/14_ai_agent)，主题索引见[主题导航](#/chapter/agent-learning-map)。

企业 Agent 培训适用于以下四类人员，各类人员共同掌握任务、证据和责任边界。

| 培训对象 | 能力目标 | 对应讲义小节 |
|---|---|---|
| 业务与转型负责人 | 场景是否值得做、责任是否明确、收益是否超过总成本与风险 | 第 1、7、12、13 节 |
| 产品流程与知识运营人员 | 输入输出、知识版本、流程分支与人工接管是否完备 | 第 3—6、9—11 节 |
| 研发与运维工程师 | 权限、工具契约、运行状态、回滚和可观测性如何实现 | 第 2、5—8、14 节 |
| 业务应用团队 | 如何核对答案、处理失败、纠正系统并保留证据 | 四个案例和第 15 节 |

培训分为两日。第一日包括智能体架构、RAG 与 Chatflow，第二日包括 Workflow、多智能体及生产线综合方案；AI 问数用于两日的证据和口径训练。

| 时段 | 讲授与操作 | 当日可交付成果 |
|---|---|---|
| 第一天上午 | 业务任务、Chatbot/Copilot/Agent、运行控制与权限边界 | 一份任务契约：输入、输出、权限、失败状态 |
| 第一天下午 | 企业知识处理、RAG、制度问答、Chatflow 与办公协作 | 带版本、有效期、引用的问答记录；对话状态图 |
| 第二天上午 | Workflow、客户分流、多智能体任务调度、安全治理 | 可逐项验收的流程状态机与人工接管规则 |
| 第二天下午 | 生产线异常综合方案、评测、经济评价、灰度推广与 NL2SQL | 四案例审计表和试点决策书 |
