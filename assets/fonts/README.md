# Course Song web fonts

Song-style glyphs are derived from Adobe Source Han Serif CN, under SIL OFL 1.1.
The modified subsets are renamed BDM Course Song to respect the reserved name.
Copyright and license notices remain in the fonts and OFL.txt.

Official source: https://github.com/adobe-fonts/source-han-serif/tree/release/SubsetOTF/CN

Regenerate after changing lecture text using scripts/subset-slide-fonts.py.
The manifest records source hashes, output hashes, and Chinese character coverage.
