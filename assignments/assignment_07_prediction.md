# Assignment 07: 预测模型基础

## 背景

本周作业围绕 `data/sample/customer_churn.csv` 的客户流失预测案例展开。请将预测模型视为管理决策系统的一部分，而不是单纯追求准确率的算法练习。

## 任务

1. 阅读 `src/bdm_decision/cases/week07_prediction.py`，运行脚本并保存输出报告。
2. 解释训练集、测试集、特征、标签和预测概率分别对应什么业务含义。
3. 使用测试集结果计算并解释 confusion matrix、accuracy、precision、recall、F1、ROC AUC 和 log loss。
4. 将阈值从 0.50 调整为 0.70，比较两种阈值下误报和漏报的管理含义。
5. 选择 3 个最高风险客户，结合月消费、预测概率和预期净价值，写出是否采取留存行动的建议。
6. 指出本案例中至少 3 个模型风险，例如样本量、数据泄漏、选择偏差、概率校准、阈值设定或公平性问题。

## 提交要求

- 一份不超过 1200 字的分析报告；
- 运行代码的关键输出；
- 至少一个表格，展示不同阈值下的评价指标；
- 一段管理建议，说明预测模型如何进入实际留存流程。
