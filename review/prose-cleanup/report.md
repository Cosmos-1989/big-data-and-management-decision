# 讲义正式语体审校

本次逐章审校十章核心讲义、专题与附录，并逐页审校十一套共458页幻灯片。网页内容页共39份，企业案例图解卡共15份。审校使用 humanizer 的结构识别方法，但以正式中文学术讲义的表述要求为准。

删除或改写的对象包括：编写与修订过程、授课组织建议、章节铺垫与编排自述、假想读者指令、口号式对比、空泛价值评价和不规范的口语表述。定义、推导步骤、分析方法、习题、操作说明、引用与适用范围具有实际内容，未按关键词机械删除。

“建议按两日组织教学”及其培训对象、时段和成果表已移至课程大纲，第14讲第一节改为“业务任务与任务契约”。“将这一教学思想用于管理决策时”改为直接论述任务意图、验收规格与实现方式。企业图解中“课堂观察”改为“分析要点”，制作与教学自述改为对象关系、分析条件和来源限定。

原始替换记录见各分项 ledger 和合并的 changes.json。记录按编辑顺序保存，部分段落经过两轮审校，记录数不是独立句子的数量。交叉复查提出的措辞问题已按 final-corrections.json 修正；旧报告中的问题属于审校过程记录。
