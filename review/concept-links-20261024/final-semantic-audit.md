# 知识链接最终语义审核

审查日期：2026-10-24。审查了 `content-source/concept-links/knowledge.json`（173个核心条目、73个背景条目）、链接生成规则和当前生成的前两讲HTML。只形成报告，未修改生产文件。审查中来源文件仍在调整，以下以读取时版本及当前HTML的实证为准。

当前 `linkAliases` 已有效关闭“数据、信息、实体、字段、记录、状态、模型、工具”等泛词的机械匹配；“上下文”也已收紧为“模型上下文／上下文占用”，普通“连接”未进入SQL连接匹配。这些限制应保留。

## 发布前应修正

| ID | 具体问题与证据 | 最小修正 |
|---|---|---|
| `data-table` | `关系表`仍作为裸自动别名。第二讲小结“通过对象、属性和关系表达经营事实”被切成“通过对象、属性和【关系表】达经营事实”，产生实际误链。 | 自动匹配仅保留`数据表`；“关系表”须按完整语句人工标记，或使用明确的词界排除“关系表达”。不可用普通“记录”补回。 |
| `llm` | `基础模型`自动跳转至“大语言模型”。基础模型可包括视觉、多模态等模型，并非LLM的同义词；第二讲“基础模型通过服务接口接受输入”已出现该错误目标。 | 移除该别名，另设“基础模型”解释与LLM的包含关系。可简释为“在广泛数据上训练并可适配多种下游任务的模型；大语言模型是其中一类”。 |
| `key` | `连接键`被解释为唯一识别记录的键。连接使用的属性可以重复，不能由参与连接推导唯一性。 | 移除`连接键`同义别名；如要点击，给其独立定义“连接条件中用于比较或配对记录的属性，不必唯一”。保留超键、候选键、主键的区分。 |
| `quadratic-cost` | `二次项`被链接到“二次努力成本”。当前企业收益函数Π(β)段的“二次项为负”同时包括努力成本和风险补偿项，不能只解释为努力成本。 | `linkAliases`只保留`二次努力成本`。数学上的二次项可在原句解释为“关于β的平方项”，不必自动链接。 |
| `normal-noise` | 泛称`噪声`被解释为正态分布噪声；总结与习题中的“测量噪声”未必以正态为定义条件。 | 只自动链接`正态噪声`；另释普通噪声为随机扰动，正态分布是本算例附加假设。 |
| `risk-aversion` | “相同期望收益下偏好较小不确定性”没有规定随机变量的比较次序，容易被误解为“方差较小就必然更偏好”。一般风险厌恶不能据方差单独比较所有分布。 | 改为“在期望效用框架中，至少同样偏好某随机收入的期望值所对应的确定收入；凹效用函数刻画弱风险厌恶。本例采用负指数效用，参数r表示常数绝对风险厌恶程度。”同步改定义块与条目摘要。 |
| `time-grain` | 定义举“一次事件、一天或一个月”为时间单位。“一次事件”是记录/事实粒度，并非时间区间单位。 | 时间粒度例子改为“小时、日、月”等；事件级记录另须注明时间戳精度。避免和事实粒度定义混同。 |
| `scd` | 条目摘要已正确改成“一组方法”，但`time-models`块和当前网页的定义仍写“保留版本及其有效区间，才能按历史时点解释记录”，未说明仅保留当前值的覆盖更新也是SCD方法。 | 同步块内定义与条目摘要，明确“不同方法保留历史的程度不同；需要按历史属性解释记录时，须采用能够保存相应版本的方法”。只改registry不足以改变正文。 |
| `potential-outcome` | `干预`被作为“潜在结果”的同义词；第一讲首表“营销干预是否有效”点击后解释的是结果，而不是行动。 | 增加“干预”独立短释，或将目标扩成确实解释“干预与潜在结果”的组合定义。干预是规定或改变行动条件；潜在结果是该行动条件下的结果。 |
| `bitemporal` | `事件发生时间`被自动解释成“双时间”。第二讲先明确区分事件发生、状态有效与入库三种时间；新定义却只解释业务有效/系统获知两轴，无法解释事件时间与有效时间的差异。 | 为三种时间各补一句，或移除宽泛别名并人工链接到原“三种时间”表；双时间只链接`双时间`等确切名称。 |

## 建议随本次一并收紧

- `star-schema`：移除`分析型建模`别名。星型模型是常见分析结构，不穷尽分析型建模。
- `shopify-global-id`：`URI`和`统一资源标识`是通用概念，不应当作Shopify产品对象的同义词。可在该背景条目内分别解释URI与Shopify的具体编码，自动链接仅留`Shopify全局标识`等明确专名。
- `third-normal-form`：正文定义完整，摘要应写清“对每个非平凡函数依赖X→A（A为单一属性）”。否则被决定端为属性集时，“属于某候选键”表述不准确。
- `conditional-probability`：现定义同时解释条件概率与条件均值，可保留组合目标，但标题宜改“条件概率与条件期望”；不要让读者误以为条件均值是条件概率的同义名称。
- `weighted-mean`：`等权平均`可链接到组合解释，但须增加“等权平均是各项权重相同的特例”；总体比率的分母权重规则适用于同一口径的分组比率，并非所有加权平均的定义。
- `constraint`：当前第一句“行动必须满足的限制”与随后的软约束可违反略有冲突，可改“比较方案时规定的条件；硬约束必须满足，软约束允许以相应代价偏离”。
- `query-operations`：基础定义只说一般连接，却把`内连接`作为别名。应补“内连接仅保留成功配对的记录，未匹配的行不保留”；不得让学生将其误解为所有连接都丢失未匹配行。
- `relationship-constraint`：例句加“在本例业务规则下”，避免把“每张订单必须属于已登记客户”写成普遍商业事实（有游客订单等其他制度）。

## 表述与循环依赖

新增正文没有严重“请按某步骤组织教学／本次更新／待处理”等过程残留，定义大体正式。值得精简的是条目中的课程自指：“两讲案例中”“本讲引用其……”“此处是……产品名”可在必要处保留消歧，但不宜每条都以教学过程开头。正文结构中“模型表示的基础术语”“字段名与英文标签”等标题具有学习功能，不必为了去元话语全部删除。

核心定义之间存在正常的解释联系，例如期望引用加权平均、条件期望引用期望；这不是循环定义。应避免把这些相邻块做成“只能点击才能知道意思”的链条。尤其概率／期望、业务对象／实体、关系／关系模式应在原地读到最小完整解释，链接仅供复核和扩展。当前第一讲的业务对象、关系约束和事实粒度基本达到这一点。

自动链接范围建议维持“专门概念+明确复合词”。凡普通动词/名词与术语共享字形，宁可保留定义及索引，不强制自动加蓝；用词出现次数或链接总数不应作为覆盖完整性的代理指标。

## 核查依据

- [Stanford CRFM：Foundation Models原始报告](https://crfm.stanford.edu/report.html)：基础模型覆盖语言、视觉等领域，不能等同LLM。
- [MIT微观经济学：不确定性与风险偏好](https://ocw.mit.edu/courses/14-01-principles-of-microeconomics-fall-2023/mit14_01_f23_full.pdf)：风险厌恶的确定收入／随机收入与凹效用表述。
- [PostgreSQL连接语义](https://www.postgresql.org/docs/16/queries-table-expressions.html)：连接根据条件配对记录，不预设连接列唯一；内外连接不同。
- [Shopify全局标识说明](https://shopify.dev/docs/api/usage/gids)：其global ID为具体应用范围内的URI用法，URI本身不是Shopify专有概念。

本报告为内容语义复核，未替代视觉、锚点、往返导航及发布后检查。


## 修复复核

2026-10-24，对上列10项修复作了一次限定范围复核，检查了知识源和重建后的两讲HTML。**10项均通过；未发现这些修复中的实质剩余错误。**

- `data-table`只自动匹配“数据表”；“关系表达”不再被切出“关系表”链接。
- `llm / foundation-model`、`key / join-field`、`potential-outcome / intervention`分别使用独立定义和目标，不再混同基础模型与LLM、连接字段与唯一键、干预与潜在结果。
- `quadratic-cost`与`normal-noise`不再自动匹配泛称“二次项”“噪声”。
- `risk-aversion`已采用确定的期望收入与有风险收入之间的偏好定义，避免仅凭较小方差概括风险厌恶。
- `time-grain`已用小时／日／月等时间单位，并与逐事件粒度区分。
- `scd`的可见定义已与知识源一致，明确覆盖更新只保留当前值，保留历史另需版本与有效区间。
- `bitemporal / time-kinds`已区分三种时间及双时间记录，“事件发生时间”链接到三类时间说明。

另核对了本次附带修复：`analytical-modeling`与星型模型已区分；Shopify条目补充URI的一般含义，裸`URI`不再作为Shopify对象名称的自动别名。新建定义块的可见正文与相应条目摘要一致。此前“建议随本次一并收紧”中的其他建议未作为本次修复验收阻断项，也未扩展为新的风格修改任务。
