# UI 文字与补充脚注复核

审查范围：`dist/app.js`、`dist/lab.js`、`dist/experiments.js`、`scripts/build-agent-extension.mjs` 中直接面向读者的标题、说明、运行提示和导航文字。以下均为只读审查结果；未修改这四个文件，也未修改实验计算过程。

## 需优先修正的口径

### 移动平均窗口采用观测期数

位置：`dist/experiments.js:10`，`statistics` 实验参数标签。

- 原文：`移动平均窗口 / 日`
- 建议：`移动平均窗口 / 观测期`

依据：`src/bdm_decision/cases/week05_statistics_dashboard.py` 的 `moving_average` 按输入数组中相邻记录的数量选取窗口；`daily_operations.csv` 的经营日期并不连续。把窗口单位写作“日”会使学生误认为连续自然日窗口。只需修改参数的展示名称，`window` 及计算过程保持不变。

### 相邻事件间隔不能直接称为等待时间

位置：`dist/experiments.js:15`，`process` 实验简介及结果表头。

- 简介原文：`从事件日志重建流程，查看等待时间、返工和合规异常。`
- 建议：`从事件日志重建流程，比较相邻事件间隔、返工与待核查的合规异常。`
- 结果字段及绘图轴原文：`平均等待小时`
- 建议：`平均事件间隔（小时）`

依据：`TransitionSummary.average_elapsed_hours` 汇总同一实例相邻事件的时间戳差，代码并未单独识别“前一步完成”和“后一步开始”。它可能包含后一个活动的处理、运输或未采集环节。结果字段名称及 `y` 所指的同名展示键需同步修改；数值表达式与算法不变。

### 缩写型实验简介可以独立理解

位置：`dist/experiments.js:8`、`:13`。

- 原文：`调整 OEE 预警阈值，比较工站的良率、在制品与交付表现。`
- 建议：`调整设备综合效率（OEE）的预警阈值，比较工站的良率、在制品与交付表现。`
- 原文：`比较朴素差异、风险分层与逆概率加权，检验平衡性。`
- 建议：`比较朴素差异、风险分层与逆概率加权（IPW），检查协变量平衡，并计算差分中的差分（DID）。`

这两项保留现有实验标题，简介补充标题中缩写的含义即可，避免另建脚注。DID 对照计算确实由现有实验程序执行，建议未增加任务。

## 可同步处理的语言问题

### 删除“原课程”“课程原有”的编写痕迹

位置：`dist/experiments.js:12`、`:18`。

- 原文：`训练原课程逻辑回归模型，调整阈值，观察误报和漏报的变化。`
- 建议：`训练逻辑回归模型，调整分类阈值，观察误报与漏报的变化。`
- 原文：`运行课程原有看板程序，输出完整图表与指标页面。`
- 建议：`运行运营看板程序，查看指标与图表页面。`

“原课程”“原有”描述材料沿革，对实验理解没有帮助。

### 容量实验中的“槽位”应能直接理解

位置：`dist/experiments.js:20`。

- 原文：`给定每小时请求数与每次检索片段数，比较云端/本地每小时成本、设计容量、槽位利用率和成本临界点；判断本地方案是否满足容量约束。`
- 建议：`给定每小时请求数与每次检索片段数，比较云端与本地方案的每小时成本、设计容量、并行服务位置占用率和成本临界点，并检查本地方案是否满足容量约束。`

“并行服务位置占用率”与讲义容量模型的定义一致。后续若希望更短，可在题面已明确并发位置后使用“服务位置占用率”。

## 无需修改的 UI 文字

`app.js` 的课程目录、阅读步骤、资源说明和检索提示能够直接指导操作，未发现必须修改的实质语言问题。阅读步骤中三个并列活动确有不同职责，不属于应机械删除的排比。

`lab.js` 中“正在准备”“运行完成”“运行环境已重置”等是与实际操作状态相对应的反馈，适合保留；它们不是误入讲义正文的编写过程说明。`display()`、SQL 编辑方法和 YAML 不能直接执行的说明同样具有操作价值。若统一润色，可将 `正在准备 SQL，请稍候…` 改为 `正在准备 SQL 运行环境，请稍候…`，但不属于必要修复。

位置：`docs/cases/semiconductor_kpi_m13_case.md` 的 `[^m13]`，及其生成的网页注释。

- 原文：`用于把指标异常关联到需求、产品、路线、设备、产能、在制品、质量、维护、交付和行动等待调查环节。`
