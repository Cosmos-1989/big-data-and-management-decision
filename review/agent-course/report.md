## 覆盖与衔接

更新前对照用户培训范围的 34 项主题，有 6 项充分覆盖、15 项部分覆盖、13 项缺失。更新后 34 项均有实质性教学位置，详见 `coverage-before.md`、`coverage-after.md` 及对应 JSON。

## 可复现资料

四个新增实验分别为制度问答、办公与研发协作、客户分流和生产线异常处理；均提供背景、任务、输入输出、约束、样例和评价标准，代码含逐步注释。可编辑方案包包含四份 Skill 配方、中立工作流契约、部署清单、完整 Python 模块、案例集和两份检查程序。包内 README 使用实际模块路径，并可在解压目录按命令复现。

教学内容的覆盖不等于所有技术都已运行：8 项有直接的可运行模拟，9 项有相关模拟但未实现该技术本身，17 项由讲义、幻灯片与方案资料承载。网页不调用真实语言模型，不连接真实日历、财务、客服或设备；向量检索、Rerank、GraphRAG、多模型调度、私有部署及七平台安装操作尚未实测。
